# CVP Practice — web luyện tập 24/7 (private)

Nội dung Space chỉ gồm `Dockerfile` + `app.py` (copy từ `deploy/hf-space/`
trong repo chính). Toàn bộ trí tuệ nằm trong repo GitHub private, được clone
lúc build; dữ liệu nằm trong 2 dataset HF private, được tải lúc khởi động.
Đăng nhập tài khoản đội là bắt buộc — không có cookie thì mọi endpoint (kể cả
ảnh) trả 401.
